# Usagi Yojimbo R8: profilo di prova Windows / Windows test profile

## Italiano

[Scarica il piccolo ZIP](plus64-usagi-r8-avvio-windows.zip) e scompattalo nella cartella della R8 che contiene `xplus4.exe` e `USAGI.D64`. Avvia **`AVVIA_USAGI_FLUIDO.cmd`**; nel menu premi **F1** per scegliere GAME, attendi un momento e premi **F7**.

Il profilo seleziona l'audio SDL, disattiva il filtro CRT e l'attesa VSync del video, e richiede la velocità normale al 100%. Mantiene il gioco entro **64+16 KiB**. La versione per il modello Plus/4 si avvia con `AVVIA_USAGI_PLUS4_FLUIDO.cmd`.

Entrambi gli avviatori sono stati provati con l'eseguibile Windows originale della R8 tramite Wine, con finestra SDL, avvio a freddo e comandi normali. Il dispositivo audio di prova è simulato: **il risultato sul PC Windows dell'utente resta da verificare**. Questa è una prova aggiuntiva; la R8 completa resta disponibile e i suoi avviatori originali permettono di tornare al profilo precedente.

## English

[Download the small ZIP](plus64-usagi-r8-avvio-windows.zip) and extract it into the R8 folder containing `xplus4.exe` and `USAGI.D64`. Run **`AVVIA_USAGI_FLUIDO.cmd`**; in the menu press **F1** to select GAME, wait a moment, then press **F7**.

This profile selects SDL audio, disables the CRT filter and video VSync wait, and requests normal speed at 100%. It retains the **64+16 KiB** memory budget. Use `AVVIA_USAGI_PLUS4_FLUIDO.cmd` for the Plus/4 model.

Both launchers were tested with the original R8 Windows executable through Wine, using an SDL window, cold startup and ordinary controls. The audio device in the test environment is simulated: **the result on the user's Windows PC still needs checking**. This is an additional test profile; the full R8 remains available, and its original launchers restore the previous profile.
