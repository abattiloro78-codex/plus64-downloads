# Alberi: anteprima corretta / corrected tree-colour preview

A sinistra la versione attuale, a destra la nuova proposta. I verdi e i tronchi hanno più volume e i quadratini d'ombra usano toni scuri colorati. Le macchie piene ai lati dei pini, provenienti dallo sfondo dentro glyph compositi, sono escluse dalla ricolorazione. Fiori e veri vuoti fra i rami restano invariati.

Left: current version. Right: proposed colours. Foliage and wood have additional shading. Exterior skyline runs embedded in composite pine glyphs retain their original black, avoiding solid coloured patches beside the crowns. Flower pixels and original air gaps are preserved.

Rendered from the real compact P64B material program by its C interpreter. Scene01 packet: 4,022 bytes within the existing 7,376-byte slot. The shared 64+16 KiB guest memory layout is retained. These files are colour-review previews; they do not replace the preceding playable release.
