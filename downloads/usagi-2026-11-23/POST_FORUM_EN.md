Usagi Yojimbo: updated plus/64 build

The updated Usagi Yojimbo port for the plus/64 software prototype is ready to try. The characters and scenery now use additional TED colours and luminance shading, including the portraits, sky, water, trees, buildings and interiors. F5 switches between English and Italian.

The same disk image is used for the C16 and Plus/4 profiles, within a total guest RAM budget of 64 KiB + 16 KiB. The colour data for the current scene are loaded from disk when changing scenes.

Download: https://raw.githubusercontent.com/abattiloro78-codex/plus64-downloads/main/downloads/usagi-2026-11-23/plus64-usagi-yojimbo-2026-11-23.zip

The ZIP includes the game disk, the required xplus4 runtime, launchers, corresponding emulator sources, editable artwork data and the complete technical developer manual in both Italian and English. Windows uses the supplied executable; the Linux launcher uses Wine.
