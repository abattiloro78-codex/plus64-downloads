## Usagi Yojimbo — R8, 23 November 2026

[Download the complete Usagi ZIP](https://raw.githubusercontent.com/abattiloro78-codex/plus64-downloads/main/downloads/usagi-2026-11-23/plus64-usagi-yojimbo-2026-11-23-r8.zip)

[Apply the uphill-path graphics correction — R8 update ZIP, 38.2 MB](https://raw.githubusercontent.com/abattiloro78-codex/plus64-downloads/main/downloads/usagi-2026-11-23/plus64-usagi-correzione-sentiero.zip). Extract into the R8 folder and start a new GAME with `AVVIA_USAGI_FLUIDO.cmd`. [Update notes, corresponding sources and IT/EN SDK addendum](./downloads/usagi-2026-11-23/CORREZIONE_SENTIERO.md).

Technical developer manual: [Italian PDF](https://raw.githubusercontent.com/abattiloro78-codex/plus64-downloads/main/downloads/usagi-2026-11-23/Manuale_Sviluppatore_PLUS64_RAM80_IT.pdf) · [English PDF](https://raw.githubusercontent.com/abattiloro78-codex/plus64-downloads/main/downloads/usagi-2026-11-23/PLUS64_RAM80_Developer_Manual_EN.pdf)

The package includes the game, required runtime, corresponding sources and complete documentation. Both machine profiles use the same D64 and the same **64 + 16 KiB total guest RAM**. Colour data for the active scene are loaded from disk at scene changes. Windows runs the supplied executable; the Linux launcher uses Wine.
